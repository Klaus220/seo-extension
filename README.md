# SEO Viewer

Firefox-расширение: во всплывающем окне показывает SEO-разметку текущей страницы — meta, link, Open Graph, Twitter и JSON-LD. Можно копировать отдельные значения и целые секции.

## Установка (Linux, временно)

1. Открой Firefox → `about:debugging#/runtime/this-firefox`
2. **Load Temporary Add-on…**
3. Выбери файл `manifest.json` из этой папки

Временное расширение снимается после перезапуска Firefox — просто загрузи снова.

## Как пользоваться

1. Открой любую обычную веб-страницу (`https://…`)
2. Нажми иконку **SEO Viewer** на панели
3. Смотри секции; **Копировать** / **Копировать секцию** — в буфер обмена

На служебных страницах (`about:…`, страница самого расширения) данные недоступны.

## Проверка на демо-странице

```bash
cd fixtures
python3 -m http.server 8765
```

Открой http://127.0.0.1:8765/sample.html и кликни иконку расширения.
